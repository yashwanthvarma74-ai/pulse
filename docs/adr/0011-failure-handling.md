# 0011. What happens when a dependency is away

Status: accepted

| Away               | What happens                                                                                                                                                                                                                                                                                                                                                       |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Redis**          | The API stays up. Feeds fall back to the newest-first feed read from MongoDB (the rebuild query), a ranked request carries on with `c.` cursors, and `/health` says `redis: false`. Posts are saved with `unprocessed: true`; the sweep fans them out when Redis returns. Realtime pauses, and the browser reconnects with backoff and refreshes its unread count. |
| **The queue**      | Same as Redis for enqueueing: a 1.5 second timeout, a log line, and the sweep. Nothing a user does fails because of it.                                                                                                                                                                                                                                            |
| **A worker**       | Jobs wait in the queue and run when one returns, with five attempts and exponential backoff. Replays are safe ([0007](0007-events-are-replay-safe.md)).                                                                                                                                                                                                            |
| **Object storage** | New uploads fail with an error the composer shows. Existing posts are unaffected except for their images.                                                                                                                                                                                                                                                          |
| **MongoDB**        | The API returns 503 from `/health` and 500 from routes. Nothing is served from stale state, because there is none to serve.                                                                                                                                                                                                                                        |
| **The gateway**    | Notifications are still saved and show up on the notifications page and in the unread count.                                                                                                                                                                                                                                                                       |

Evidence: `feed.test.ts` ("when Redis is away"), `auth.test.ts` (health with Redis away), `handlers.test.ts` (the
sweep).
